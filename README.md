## 🚀 Featured Projects

### 🛡️ [SHIELD](https://github.com/heysudhuu/SHIELD)

**Python Desktop Cybersecurity Toolkit**

A desktop-based cybersecurity toolkit bringing security utilities together in an intuitive application interface.

- 🔐 Security-focused utilities
- 🖥️ Desktop GUI application
- 🐍 Python-based implementation
- 🧩 Modular architecture
- ⚙️ Practical security tooling

### 🎣 [PhishGuard-AI](https://github.com/heysudhuu/PhishGuard-AI)

**AI-Powered Phishing Detection**

An intelligent phishing detection project designed to analyze suspicious URLs and help identify potential phishing threats.

- 🔎 URL analysis
- 🚨 Suspicious link detection
- 🤖 AI-assisted threat detection
- 🌐 JavaScript-based development
- 🛡️ Security awareness and threat analysis

### 🏏 [Cricket AI Analyzer](https://github.com/heysudhuu/cricket-ai-analyzer)

**Computer Vision-Based Cricket Performance Analysis**

An AI-powered sports analytics application that uses computer vision and pose estimation to analyze cricket movements and shot mechanics.

- 🧠 YOLO-based pose estimation
- 👤 Player tracking and movement analysis
- 📐 Joint-angle calculations
- 🏏 Shot phase detection
- 📊 Performance scoring and analytics
- 🎞️ Video processing with OpenCV
- 📁 CSV data export

### ✋ [Hand Gesture Controlled Virtual Keyboard](https://github.com/heysudhuu/Hand-Gesture-Controlled-Virtual-Keyboards)

**Touchless Human-Computer Interaction**

A gesture-controlled virtual keyboard that enables real-time interaction with a computer through hand movements.

- ✋ Real-time hand tracking
- 👆 Gesture-based typing
- 👁️ OpenCV & MediaPipe
- 🖱️ PyAutoGUI automation
- ⚡ Touchless interaction
